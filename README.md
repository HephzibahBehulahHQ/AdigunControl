# Adigun Control

Private source repository for admin.hephzibahbehulah.com.

Build the Admin assets with `node platform/build.mjs` and run the local checks with `node --test platform/*.test.mjs`. The Worker configuration has no public hostname or workers.dev endpoint enabled. The Admin custom domain can move after signed-in verification in a Cloudflare Access preview.

Public marketing pages and individual product deployments use their own repositories.
